# Contributing to EMC Study Hub

EMC Study Hub is an early-stage bilingual educational quiz prototype for Emergency Medical Care students. Open index.html in a modern browser to run it locally; no installation is needed.

## Current features
- Six introductory assessment questions in English and Arabic.
- Immediate answer feedback and first-attempt scoring.
- Three-second automatic progression after correct answers.
- Mistake-only review rounds.

## Contributions
Report bugs or suggest improvements through GitHub issues. Contributions to accessibility, Arabic translations, and educational questions are welcome. Provide reliable references for new medical content and avoid patient-identifiable information or copyrighted course materials.

## Limitations
This is an educational prototype, not a validated clinical tool or a substitute for professional training. Clinical simulations and expanded question banks are future goals, not current features.
